Get your tabs back from a Tab Session Manager export

Some people report that re-importing a Tab Session Manager export shows "Sessions imported" and then nothing appears. This page opens those export files and shows every session, window and tab as a link you can click. It also gives you three files to download: a copy of the export with a new id on each session, a bookmarks file any browser can import, and a plain text list.

Choose one or more .json files exported by Tab Session Manager. The files are read in your browser and nothing in this page's code sends them anywhere; the page's security policy also stops its scripts from making network requests.

One user who edited and re-imported an export found that the import worked "only after I modified the id of the session" in the file. This copy gives every session a new id and a new last-edited time, and otherwise changes nothing, apart from filling in a missing field the import checks for (name, tag, tab count, date or start time). Import it from the extension's settings, under Import Sessions. It has not been tried in the extension yet, and it is not known to fix every report; if the session still does not show, use one of the two files below.

The bookmarks file has one folder per session and one subfolder per window; import it from your browser's bookmarks manager. Addresses that are not web or file links (for example the browser's own pages) are left out of it and are not clickable here, but they are in the text list.
